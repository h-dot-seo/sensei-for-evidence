# Rights and third-party material

The owner has authorized public posting of this framework. A reuse license has not
been selected; this repository must not be described as licensed open source yet.
Public access alone does not grant a general right to copy, modify or redistribute.

This release includes owner-supplied framework code, generalized method descriptions,
and newly written examples/tests. It does not bundle third-party libraries, articles,
books, figures, private databases, real researcher packages or source corpora.
The standard library is a runtime dependency, not redistributed source code.

If adding third-party material later, verify its exact license, attribution and
redistribution terms first. Lawful reading access is not redistribution permission.
Do not commit a paper's full text, extracted chunks, figures or derived corpus merely
because it was accessible online. Prefer source identifiers and links when appropriate.
